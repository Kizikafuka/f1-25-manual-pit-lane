# Manual Pit Lane

Drive the pit lane and park on your marks yourself while the crew does the stop. Use the game's Immersive pit stops; the quick-time event is removed. Ctrl+F7 switches it. Experimental.

A Swofty Launcher addon for F1 25, by Kizikafuka. Version 0.3.9.

- Install it from the Swofty Addon Browser.
- Source: `native/src` (C++), manifest `swofty.json`. Shared headers are in `common/`.
- Build: Zig (`zig c++ -target x86_64-windows-gnu -std=c++23 -shared`) with the Swofty SDK headers in `native/include`.
